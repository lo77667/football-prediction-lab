# بوابة الضمان الشاملة

لا تُعد النسخة قابلة للانتقال إلى تشغيل تجريبي إلا بعد تحقق البنود الآتية:

| المجال | معيار القبول | الحالة الحالية |
|---|---|---|
| البيانات | المصدر، الإصدار، وقت التنزيل، والتغطية موثقة | متحقق للعينة المحلية |
| النظافة | لا أهداف سالبة، لا أسماء فارغة، ولا معرّفات مكررة | متحقق |
| الزمن | التقسيم مرتب زمنيًا ولا يوجد خلط عشوائي | متحقق |
| التسرب | الميزات الحالية لا تستخدم نتيجة المباراة الحالية | متحقق باختبارات وحدة |
| الاحتمالات | كل الاحتمالات ضمن [0, 1] | متحقق بعقود واختبارات |
| السجل | التوقع يسبق النتيجة والسلسلة التجزئية قابلة للتحقق | متحقق |
| التقييم | الدقة وBrier وLog Loss والمعايرة محفوظة | متحقق على عينة واحدة |
| التعلم | لا يعتمد نموذج جديد دون اختبار مستقبلي مستقل | متحقق؛ آخر دورة مرفوضة تحفظيًا |
| الوكيل | قراءة وتفسير فقط، ولا يضيف وقائع غير موثقة | متحقق |
| الأسرار | لا مفاتيح أو بيانات اعتماد في Git | متحقق عبر `.gitignore` وفحص المستودع |
| الاستمرارية | الاختبارات والأسلوب يعملان محليًا وفي CI | متحقق محليًا؛ ينتظر نتيجة CI بعد الدفع |

## قرار الضامن

لا يكفي نجاح الاختبارات البرمجية لإثبات جودة التنبؤ. قبل نشر توقعات عامة، يجب توسيع المواسم، والتحقق من تعريفات الأسواق، ومراقبة أداء خارج العينة، وتوثيق أي تغيير في المصدر أو النموذج.
