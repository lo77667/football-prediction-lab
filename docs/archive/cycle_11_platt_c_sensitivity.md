# دورة 11: حساسية Platt لمعامل C

**الحالة:** المرشح مستقر وصالح كفحص بحثي إضافي؛ لم يُنشأ اعتماد تجاري أو خدمة عامة.

## التصميم

استُخدمت `LEGACY_FEATURE_COLUMNS` الثابتة لتجنب إعادة استعمال اختيار ميزات holdout. في كل طية، دُرّب النموذج الأساسي على المواسم الأسبق، ودُرّب Platt على احتمالات موسم التحقق السابق، ثم اختُبر على الموسم التالي. جرى تشغيل ثلاث قيم محددة مسبقًا لمعامل Logistic Regression في المعاير: `C=0.1` و`C=1.0` و`C=10.0`. لم تُستخدم نتيجة الاختبار لاختيار القيمة الأفضل؛ الغرض هو قياس الحساسية لا الانتقاء بعديًّا.

## النتائج عبر 8 طيات و3040 صفًا

| C | Brier الأساسي | Brier Platt | Log Loss الأساسي | Log Loss Platt | ECE Platt | فوز مشترك عبر الطيات |
|---:|---:|---:|---:|---:|---:|---:|
| 0.1 | 0.2504479 | 0.2491240 | 0.6940555 | 0.6914095 | 0.0295917 | 7/8 |
| 1.0 | 0.2504479 | 0.2491010 | 0.6940555 | 0.6913623 | 0.0335351 | 7/8 |
| 10.0 | 0.2504479 | 0.2491882 | 0.6940555 | 0.6915366 | 0.0362395 | 6/8 |

بوابة المقارنة مع النموذج الأساسي قبلت القيم الثلاث جميعًا لأنها حسّنت Brier وLog Loss المتوسطين ولم ترفع ECE المتوسط. هذه النتيجة تدعم أن التحسن ليس حساسًا بشدة لقيمة C ضمن هذا النطاق، لكنها لا تجعل اختيار `C=1.0` اختيارًا نهائيًا؛ فالاختيار النهائي يحتاج بروتوكول validation معلنًا مسبقًا أو بيانات مستقبلية جديدة.

## الاستنتاج المنضبط

توجد إشارة بحثية متماسكة لتحسن Platt على النموذج الأساسي legacy، وتبقى `C=1.0` قريبة جدًا من `C=0.1` و`C=10.0`. بالمقابل، لا يجوز ترجمة ذلك إلى احتمال نجاح مستقبلي أو منفعة اقتصادية. لا تزال كل النتائج ضمن نفس العينة التاريخية، ولم تُجمع بيانات نوعية أو أخبار جديدة، ولم تُنفذ مراهنات أو نشر عام.

## الأدوار

| الشخصية | المراجعة |
|---|---|
| المنفذ | أضاف تمرير C صريحًا واختبار قيم الحساسية الثلاث |
| المدقق | شغّل 56 اختبارًا، Ruff، وcompileall؛ ورفض C غير الموجب باختبار صريح |
| المراجع | تحقق من ثبات الطيات والميزات وأن C لم تُنتقَ من test |
| الباحث | حافظ على فصل المعايرة عن الاختبار وعلى سياسة المصادر والحقوق القائمة |
| المطور | أضاف تقريرًا منظمًا يقارن المتوسطات والفوز المشترك عبر الطيات |
| الضامن | راجع عدم دخول `reports/generated/` أو البيانات المحلية إلى Git |
