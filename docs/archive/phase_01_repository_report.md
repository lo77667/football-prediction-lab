# تقرير المرحلة 01 — تهيئة المستودع

## النطاق

تم إنشاء مستودع GitHub خاص باسم `football-prediction-lab` على الفرع `main`. المشروع بحثي فقط، ولا يحتوي على تنفيذ مراهنات أو نشر خدمة.

## ما تم إنجازه

- تهيئة حزمة Python قابلة للتثبيت.
- إنشاء مجلدات منفصلة للبيانات الخام والمعالجة والميزات والنماذج والتقييم والسجل والوكيل.
- إضافة عقود Pydantic للمباراة والتوقع والنتيجة والتقييم.
- إضافة إعدادات YAML للنسخة الأولى: سوق BTTS، توقع قبل المباراة، وسياسة منع تسرب المستقبل.
- إضافة README وقواعد Git لتجنب تسريب الأسرار والبيانات المحلية.
- إضافة اختبارات أولية للعقود وتشغيل CLI يعرض نطاق المشروع.

## مرور الأدوار

### المنفّذ
أنشأ الهيكل والملفات الأساسية والاختبارات.

### المدقّق
شغّل `pytest` و`ruff`. النتيجة: 3 اختبارات ناجحة، وفحص أسلوب ناجح.

### المراجع
تحقق من أن النطاق محصور في BTTS وتوقع قبل المباراة، وأن المستودع لا يحتوي على مفاتيح أو بيانات خام.

### الباحث
وثّق مصادر أولية محتملة للبيانات في نطاق العمل: OpenFootball، Football-Data.co.uk، StatsBomb Open Data، وOpenLigaDB. لم تُضمَّن أي بيانات خارجية بعد.

### المطوّر
اقترح إبقاء النسخة الأولى بلا API key، وتأجيل سوق البطاقات والوكيل اللغوي حتى يثبت خط البيانات والنموذج الأساسي.

### الضامن
أعاد تشغيل الاختبارات وفحص بنية المشروع والتوافق بين README و`configs/base.yaml` و`contracts.py`. معايير القبول متحققة للمرحلة الحالية.
