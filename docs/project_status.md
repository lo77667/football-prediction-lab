# الحالة النهائية للإصدار 0.1.0

## هوية المشروع

المشروع هو مختبر بحثي قابل للتدقيق لتوقع أسواق كرة القدم. الإصدار الحالي يدعم BTTS وسوق مجموع البطاقات الصفراء فوق 3.5، مع توقعات قبل المباراة، سجل توقعات متسلسل، كشف مؤجل للنتائج، مقاييس احتمالية، سجل أخطاء، وبوابة إعادة تدريب.

## ما هو جاهز

| المكوّن | الحالة |
|---|---|
| مستودع GitHub خاص | جاهز، الفرع `main` |
| جامع Football-Data CSV | جاهز للعينة التاريخية |
| تنظيف وتوحيد المباريات | جاهز ومختبر |
| ميزات BTTS قبل المباراة | جاهزة ومختبرة ضد التسرب |
| نموذج BTTS أساسي | جاهز للاختبار البحثي |
| سجل توقعات متسلسل | جاهز وقابل للتحقق |
| تقييم الدقة والمعايرة | جاهز |
| سجل التعلم وبوابة إعادة التدريب | جاهز، وآخر مرشح مرفوض تحفظيًا |
| ميزات ونموذج البطاقات | جاهز كمرحلة متقدمة أولية |
| وكيل تفسير قراءة فقط | جاهز |
| GitHub Actions quality gate | ناجح |

## آخر نتائج موثقة

تدرب نموذج BTTS على 266 مباراة واختُبر على 114 مباراة محجوزة زمنيًا. في نافذة الاختبار النهائية ذات 57 مباراة، كانت الدقة 0.5088، وBrier Score قدره 0.2562، وLog Loss قدره 0.7060. في سوق البطاقات، استُخدمت 114 مباراة للحجز، وكانت الدقة 0.5263 وBrier Score قدره 0.2551 وLog Loss قدره 0.7038.

هذه أرقام بحثية أولية لعينة محدودة، ولا تعني ربحية أو ضمانًا أو تفوقًا عامًا. لا يعتمد المشروع نموذجًا جديدًا إلا بعد اختباره على نافذة مستقبلية مستقلة وكافية.

## القيود المعروفة

التغطية الحالية تعتمد على موسم واحد من الدوري الإنجليزي الممتاز، وبعض الحقول لا تتضمن الحكم أو الإصابات أو التشكيلات أو سياق المباراة. بيانات البطاقات مأخوذة من حقول المصدر المتاحة، ويجب تثبيت تعريف السوق عند استخدام مزود مختلف. كما أن البيانات الخام محلية وغير مرفوعة إلى المستودع بسبب الحجم وشروط إعادة الاستخدام.

## التحقق النهائي

اجتاز المشروع 26 اختبارًا آليًا محليًا، وفحص Ruff، وفحص فروق Git، وفحص أنماط الأسرار، كما نجح Workflow `quality-gate` على GitHub. آخر دورة تعلم سُجلت كمرفوضة لأن نافذة الاختبار المستقلة الحالية صغيرة، وهو سلوك مقصود لحماية نزاهة التجربة.

## الخطوة التالية المقترحة

توسيع البيانات إلى مواسم ودوريات إضافية، ثم إعادة تشغيل التجربة كاملة دون تغيير بروتوكول الزمن، قبل إضافة أي ميزات جديدة أو ربط نموذج لغوي خارجي.
