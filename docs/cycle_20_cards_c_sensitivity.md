# دورة 20: حساسية C لمعايرة البطاقات

**الحالة:** النتيجة مستقرة نسبيًا بحثيًا، لكن فواصل عدم اليقين السابقة ما تزال تمنع اعتماد التفوق على constant.

## النتائج عبر 8 طيات و3040 صفًا

| C | Brier Platt | Log Loss Platt | ECE-10 | الفوز المشترك مع الأساس |
|---:|---:|---:|---:|---:|
| 0.1 | 0.2473461 | 0.6881192 | 0.0712719 | 6/8 |
| 1.0 | 0.2472356 | 0.6879017 | 0.0716077 | 6/8 |
| 10.0 | 0.2472360 | 0.6879236 | 0.0749179 | 6/8 |

تحسنت Brier وLog Loss المتوسطتان لجميع القيم الثلاث مقارنة بالأساس، وقبلتها بوابة المعايرة الداخلية. الفروق بين `C=1.0` و`C=10.0` صغيرة جدًا، لكن هذا لا يبرر اختيار قيمة بعد رؤية الاختبار؛ الغرض من الدورة هو الحساسية لا الضبط بعديًّا.

## القراءة المنهجية

تظل نتيجة bootstrap cards السابقة هي الحارس الأقوى: فاصل Brier وفاصل Log Loss لفروق Platt ناقص constant عبرا الصفر. لذلك لا تتحول حساسية C إلى إثبات تفوق؛ هي فقط تُظهر أن التحسن المتوسط داخل النموذج المعاير ليس حساسًا بشدة لهذه القيم المحددة مسبقًا.

## الحقوق والضمان

كل الحسابات على البيانات الكمية المحلية الموثقة. لم تُجمع أخبار أو محتويات مقيدة، ولم تُستخدم أحداث نوعية مصطنعة أو نصوص مولدة كمصدر حقيقة. سيُعاد تشغيل الاختبارات وRuff وcompileall وCI قبل دفع التقرير.
