# تقرير دورة التطوير الثانية

## النطاق

واصلت الدورة العمل ضمن المختبر الخاص القابل للتدقيق، من دون نشر خدمة عامة أو تنفيذ مراهنات. أضيفت طبقة تجميع للأحداث النوعية الموثقة زمنيًا، ومحمل JSONL صارم، وتجربة ablation تفصل المسار الكمي عن الهجين. كما أضيف ضبط للإعدادات على validation فقط، وتجربتا walk-forward عادية ومتداخلة، ثم توسعت العينة محليًا من سبعة إلى عشرة مواسم EPL.

## عزل المسار النوعي

يستخدم `build_qualitative_features` نقطة قطع خاصة بكل مباراة، ويقبل فقط الأحداث التي تحقق `available_at_utc <= kickoff_utc`. الأحداث اللاحقة لا تدخل العد أو متوسط الثقة. يرفض العقد الأحداث بلا مصدر، والقيم غير المؤرخة، والأحداث التي تخص مباراة أخرى. ويمنع محمل JSONL المعرفات المكررة.

لم تُجمع أحداث نوعية تاريخية ولم تُستخدم في تدريب فعلي. تشغيل smoke test بملف أحداث فارغ أعاد اختيار `quantitative_only`، وهو السلوك الصحيح لأن عدم وجود دليل نوعي لا يبرر اختلاق ميزات.

## بحث المصدر والحقوق

أظهر فحص StatsBomb Open Data أن مستودع البيانات يضم أحداثًا وlineups لبعض المسابقات، مع شروط ذكر StatsBomb عند نشر التحليل. كما أظهر فحص `competitions.json` تغطية Premier League للرجال لموسمي `2003/2004` و`2015/2016` ضمن القائمة الحالية، وليس مواسم EPL العشرة المستخدمة هنا. لذلك لم يُستخدم StatsBomb لمطابقة مباريات هذه العينة. وثقت التفاصيل في `docs/qualitative_source_research.md`، مع اعتبار OpenFootball مصدرًا عامًا موجهًا للنتائج لا مصدرًا كافيًا للإصابات أو الأخبار.

## توسيع العينة

أضيفت مواسم `1516` و`1617` و`1718` إلى المواسم السبعة السابقة. بلغ الناتج المحلي 3800 مباراة بلا تكرار، من 2015-08-08 إلى 2025-05-25 UTC، ومعدل BTTS المجمع 0.5234. بقيت ملفات البيانات الخام والمعالجة وتقارير generated خارج Git.

| التجربة | المقياس المتوسط عبر walk-forward | Legacy / الأساسي | الموسع / المحسن |
| --- | ---: | ---: | ---: |
| BTTS: accuracy | 0.5184 | 0.5129 |
| BTTS: Brier | 0.2502 | 0.2547 |
| BTTS: Log Loss | 0.6936 | 0.7033 |
| البطاقات: accuracy | 0.5249 | 0.5251 |
| البطاقات: Brier | 0.2507 | 0.2533 |
| البطاقات: Log Loss | 0.6950 | 0.7009 |

تؤكد هذه النتائج أن زيادة العينة وحدها لم تثبت تفوق الميزات الموسعة. بقي BTTS legacy أفضل احتماليًا في المتوسط، بينما كان فرق accuracy في البطاقات هامشيًا ولم يصاحبه تحسن في Brier أو Log Loss.

## walk-forward المتداخل

في التجربة المتداخلة، استُخدم الموسم السابق كتحقق لاختيار `C` و`class_weight`، ثم دُمج مع التدريب، واختُبر الموسم التالي مرة واحدة. متوسط BTTS عبر خمسة folds كان accuracy `0.5095` وBrier `0.2509` وLog Loss `0.6951`. متوسط البطاقات كان accuracy `0.5563` وBrier `0.2455` وLog Loss `0.6844`. هذه نتائج بحثية وليست ضمانًا لاستقرار المستقبل، ولا تُستخدم لاستخراج إشارة مراهنة.

## القرار

تُقبل بنية المسار الهجين والاختبارات الوقائية، لكن لا يُفعّل التدريب النوعي لغياب مجموعة أحداث تاريخية موثقة ومصرح بها ومطابقة للمباريات. تُسجل نتائج العشرة مواسم والـwalk-forward بوصفها أدلة على حساسية النموذج، لا بوصفها نجاحًا أو ربحية. المعيار المستمر للاعتماد هو تحسن Brier وLog Loss خارج العينة، مع اختبار معايرة وفصل زمني واضح.
