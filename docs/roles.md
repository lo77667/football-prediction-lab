# بروتوكول الأدوار

كل مرحلة تمر على الأدوار الآتية بالترتيب، ولا تُعد مكتملة إلا بعد تسجيل نتيجة كل دور.

## المنفّذ

يبني التغيير المطلوب ضمن نطاق المرحلة، ويضيف اختبارات مناسبة، ولا يوسّع النطاق دون توثيق.

## المدقّق

يفحص الكود والاختبارات وعقود البيانات ومخاطر تسرب النتائج. يسجل العيوب القابلة لإعادة الإنتاج بدل الاكتفاء بانطباع عام.

## المراجع

يقارن الناتج بمعيار قبول المرحلة، ويتحقق من أن ما نُفذ يطابق النطاق وأن المستندات لا تتعارض مع الكود.

## الباحث

يتحقق من مصادر البيانات والتراخيص والتعريفات، ويثبت أي ادعاء خارجي برابط أو سجل مصدر مناسب.

## المطوّر

يقترح تحسينات قابلة للتنفيذ، لكنه لا يفرضها داخل المرحلة الحالية. كل اقتراح يذكر الفائدة والتكلفة والمخاطر وسبب تأجيله أو اعتماده.

## الضامن

يجري مراجعة شاملة مستقلة: يشغل الاختبارات، يراجع التغييرات، يفحص قابلية إعادة الإنتاج، ويتأكد من عدم وجود أسرار أو نتائج مستقبلية أو ادعاءات غير مثبتة. لا يعلن المرحلة ناجحة إلا إذا تحققت معايير القبول، أو يفتح دورة إصلاح جديدة للمنفّذ.

## قاعدة الدورة

```text
المنفّذ → المدقّق → المراجع → الباحث → المطوّر → الضامن
      ↑                                        │
      └──────── دورة إصلاح عند وجود ملاحظات ───┘
```
