# دورة 14: عدم اليقين المقترن لـPlatt مقابل constant

**الحالة:** لا يوجد إثبات قوي لتفوق المرشح على baseline بعد فحص عدم اليقين.

## البروتوكول

استُخدمت احتمالات حقيقية مولدة من ثماني طيات زمنية، بإجمالي 3040 صفًا، على `LEGACY_FEATURE_COLUMNS` وPlatt عند `C=1.0`. في كل طية، أُعيد أخذ صفوف الاختبار مع الإرجاع بطريقة مقترنة؛ أي إن Platt وconstant واجها الصفوف نفسها داخل كل إعادة. حُسب فرق المقياس على صورة **Platt ناقص constant** ثم أُخذ متوسط الطيات. استُخدم bootstrap percentile بعدد 2000 إعادة وبذرة 42.

## النتائج

| فرق Platt − constant | المتوسط | فاصل percentile 95% |
|---|---:|---:|
| Brier | -0.0004785 | [-0.0018811, 0.0009313] |
| Log Loss | -0.0009433 | [-0.0037996, 0.0019395] |

القيمة السالبة في المتوسط تميل لصالح Platt لأن الأقل أفضل، لكن كلا الفاصلين يعبر الصفر. لذلك لا توجد في هذا الفحص العيني دلالة مستقرة على تفوق Platt على baseline الثابت، رغم أن بوابة المتوسطات قبلته سابقًا. لا يجوز تحويل متوسط التحسن الصغير إلى ادعاء تفوق مثبت أو منفعة مالية.

## تفسير منضبط

هذا bootstrap يصف عدم يقين العينة التاريخية ولا يمثل تنبؤًا بالمواسم المستقبلية. كما أنه لا يصحح كل مصادر عدم اليقين، مثل اختيار المواسم، تصميم الميزات، أو تغير العلاقة عبر الزمن. لكنه يضيف حارسًا مهمًا: قرار الاعتماد لا ينبغي أن يعتمد على المتوسطات وحدها عندما يمر فاصل الفرق بالصفر.

## الأدوار

| الشخصية | النتيجة |
|---|---|
| المنفذ | أضاف bootstrap مقترنًا يحافظ على أزواج التنبؤ داخل كل طية |
| المدقق | راجع البذرة وعدد الإعادات، وشغّل Ruff وcompileall |
| المراجع | تحقق من أن المقارنة على نفس الصفوف ونفس الطيات وأن الإشارة السالبة تعني تحسنًا |
| الباحث | ربط النتيجة بمبدأ عدم اليقين وعدم تقديم المتوسط كحقيقة عامة |
| المطور | فصل بوابة التحسن المتوسط عن فحص الثقة/الاستقرار |
| الضامن | أبقى تقرير bootstrap المولد خارج Git، وثبت فقط الكود والتوثيق |

## القيود والحقوق

البيانات محلية وكمية ومصدرها موثق سابقًا. لم تُجمع أخبار أو محتويات مقيدة، ولم تُستخدم بيانات نوعية اصطناعية أو نصوص LLM كمصدر حقيقة. لا توجد مراهنات أو خدمة عامة أو ادعاءات اقتصادية.
