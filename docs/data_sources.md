# مصادر البيانات — النسخة الأولى

## المصدر الأساسي للتجربة التاريخية

تستخدم النسخة الأولى ملفات CSV التاريخية من [Football-Data.co.uk](https://www.football-data.co.uk/downloadm.php). هذه الملفات مناسبة لبناء اختبار أولي لأن النتائج والتواريخ وأسماء الفريقين تأتي في شكل جدولي قابل للمعالجة، وتتوفر معها احتمالات تاريخية في بعض الأعمدة. لا يُفترض أن مجانية التنزيل تعني تلقائيًا حرية إعادة التوزيع؛ لذلك يحتفظ المشروع بسجل المصدر ولا يعيد نشر الملفات الخام داخل المستودع.

## مصدر بديل للنتائج والجداول

يُستخدم [OpenFootball](https://openfootball.github.io/) للتحقق من النتائج والجداول التاريخية. المشروع يصف بياناته بأنها مفتوحة المجال العام، لكن يجب فحص تغطية كل مسابقة وموسم قبل إدخالها في تجربة محددة.

## مصدر الأحداث التفصيلية لاحقًا

يُحفظ [StatsBomb Open Data](https://github.com/hudl/open-data) كخيار لمرحلة لاحقة عند بناء سوق البطاقات أو التسديدات. يغطي مسابقات ومباريات منتقاة، ويطلب نسبة المصدر عند نشر التحليل مع الالتزام بملف الترخيص.

## مصدر النتائج العامة

يمكن استخدام [OpenLigaDB](https://www.openligadb.de/) للحصول على نتائج ومواعيد عبر JSON دون مصادقة عند الاسترجاع بحسب صفحة المشروع. البيانات مجتمعية وتحت ODbL، لذلك تُستخدم كمرجع أو مصدر مساعد بعد فحص التعارضات.

## قواعد الجمع

لا تُحفظ مفاتيح API أو بيانات اعتماد في المستودع. تُحفظ الملفات الخام محليًا أو في تخزين مخصص، وتُحفظ داخل GitHub فقط ملفات الإعدادات، مخططات البيانات، التجزئات، وتقارير الجودة. كل عملية جمع تسجل الرابط، وقت التنزيل، حجم الملف، وتجزئة SHA-256.

لا تُخلط مصادر متعددة في جدول واحد قبل توحيد أسماء الفرق والمنطقة الزمنية وتعريف النتيجة. وعند تعارض مصدرين، يبقى التعارض معلّمًا ولا يُحل بصمت.
