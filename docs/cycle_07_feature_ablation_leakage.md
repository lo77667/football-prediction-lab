# تقرير دورة التطوير السابعة

## النطاق

ركزت الدورة على تدقيق تسرب الصف الحالي وتجارب ablation منفصلة لـBTTS والبطاقات، مع إبقاء كل اختيار للميزات محصورًا في validation عند الحاجة. لم تُرفع البيانات المحلية أو التقارير المولدة، ولم تُنفذ مراهنات أو نشر عام.

## تدقيق التسرب

غُيرت أهداف وتسديدات وركنيات صفوف مختارة من العينة الحقيقية، ثم أُعيد بناء الميزات. بقي متجه ميزات المباراة الحالية ثابتًا في BTTS والبطاقات للصف الأول والأوسط والأخير. يسمح التصميم بتغير ميزات المباريات اللاحقة التي ترى المباراة المعدلة ضمن تاريخها. هذا فحص mutation موضعي، وليس بديلًا عن المراجعة الزمنية الشاملة.

## BTTS ablation

قورنت أربع عائلات: legacy، rolling_only، rolling_plus_context، وfull_expanded. اختارت validation عائلة `rolling_plus_context`، ثم حققت على الاختبار Brier `0.2478` وLog Loss `0.6887`. لا يمثل ذلك تفوقًا عامًا؛ لأن التجربة split واحد، ولأن بوابة walk-forward والمقارنة مع الثابت ما زالت معيار الاعتماد.

## البطاقات ablation

قورنت legacy وteam_context وreferee_enhanced. اختارت validation النسخة referee-enhanced، ثم بلغ اختبارها Brier `0.2444` وLog Loss `0.6818`. هذه النتيجة لا تنقض نتائج walk-forward السابقة التي رفضت النسخة المعززة في المتوسط؛ بل توضح حساسية الاستنتاج لنوع التقسيم. لذلك لا تعتمد النسخة إنتاجيًا.

## الأدوار

| الشخصية | المراجعة | النتيجة |
|---|---|---|
| المنفذ | أضاف mutation audit وBTTS/cards ablation | مكتمل |
| المدقق | شغّل 48 اختبارًا وRuff وcompileall | ناجح |
| المراجع | تحقق من أن test لا يختار الميزات إلا حيث صرحت التجربة بذلك | مطابق |
| الباحث | أبقى النوعي المؤرخ القابل للحقوق فقط خارج التدريب الحالي | سليم |
| المطور | أوصى بإعادة الاختبار عبر walk-forward لا split واحد | منفذ كقاعدة اعتماد |
| الضامن | راجع CI، نظافة الفرع، وعدم رفع التقارير والبيانات | قيد الإكمال النهائي |

## القرار

تُقبل أدوات التدقيق وتجارب ablation بوصفها أدوات بحثية. لا يُعلن تحسن عام لأي سوق. يبقى الحكم referee-enhanced غير معتمد، ويبقى BTTS rolling_plus_context مرشحًا يحتاج walk-forward مستقلًا وفواصل عدم يقين قبل أي اعتماد.

## الضمان النهائي

بعد الدفع، نجحت GitHub Actions في الاختبارات وRuff وcompileall. بقي الفرع `main` نظيفًا ومتزامنًا مع `origin/main`. بلغ مجموع الاختبارات الآلية 48، ولم تُرفع ملفات البيانات أو التقارير المولدة.
