# دورة 22: حساسية نافذة معايرة cards

**الحالة:** تحسن بحثي متكرر عبر الإعدادات، لكن bootstrap cards السابق ما يزال يعبر الصفر.

تحسنت المقاييس الاحتمالية في المتوسطات الثلاث، لكن أعداد الطيات مختلفة، فلا يصح إعلان نافذة واحدة كأفضل إعداد بعد النظر إلى النتائج. الأهم أن فواصل bootstrap المقترنة لسوق البطاقات عند نافذة موسم واحد عبرت الصفر؛ لذلك تُسجل هذه النتائج كحساسية وصفية وليست اعتمادًا.

لم تُجمع أي أخبار أو محتويات جديدة، ولم تدخل بيانات نوعية غير موثقة أو نصوص مولدة في التدريب. تظل الدراسة كمية محلية، خاصة، وتجريبية فقط.
